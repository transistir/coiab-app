O COIAB é um app de monitoramento territorial participativo. Cada pessoa registra
o que vê no território — uma árvore, uma área de caça, um alerta de fogo — e as
observações ficam organizadas por área de trabalho. O app foi pensado para uso em
campo: os dados ficam no dispositivo e a troca com outras pessoas acontece entre
os aparelhos.

Uma **organização** (chamada de "território" nas telas) reúne os projetos de um
mesmo território. Hoje o app trabalha com duas áreas padrão: **Monitoramento
Territorial** e **Alertas**. A organização define quem participa e quais
categorias cada área oferece.

Este guia cobre a primeira abertura do app, a entrada ou criação de uma
organização e a criação de uma observação:

- [Primeiros passos](/coiab-app/primeiros-passos/) — da instalação ao dispositivo pronto.
- [Organização](/coiab-app/organizacao/) — preparar, convidar e trocar de território.
- [Criar uma observação](/coiab-app/criar-observacao/) — do mapa ao registro salvo.

Ainda não estão neste guia: Menu, Mapa, Paneiro, Configurações e Exchange. Essas
telas já existem no app e ficam para uma próxima etapa da documentação.
